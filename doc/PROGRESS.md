> 기준일: 2026-10-16 (Asia/Seoul)

## 1. 현재 단계

**Phase 1 / Day 1 진행 중.** WPF 셸과 프로필 연결 UI가 구현되었고, EC2/RDS/S3 읽기 조회 코드와 임시 리소스 조회 화면을 추가했다. 각 서비스의 실제 목록 정상 조회는 사용자 수동 확인을 받았고, Mock 및 빈 결과·오류 경로 검증은 미확인이다. 그룹 등록·JSON 복원·기본 상태 대시보드가 남아 있다. `DEVELOPMENT_PLAN.md`의 Day 1 완료 게이트를 통과하지 않았으므로 Day 2와 Phase 2는 시작하지 않았다.

아래의 `완료`는 해당 범위의 **코드 구현 상태**를 뜻한다. 빌드·Mock·실제 AWS 검증 결과는 §4에서 별도로 판정한다. 일부만 구현했거나 단계 완료 조건이 남으면 `진행 중`, 핵심 코드가 없으면 `미완료`로 표시한다.

## 3. 현재 코드에 구현된 주요 기능

- WPF 다크 테마 셸, 공통 `ResourceDictionary`, MVVM 내비게이션, 대시보드 빈 상태와 그룹 화면 이동 버튼.
- AWS 연결 관리 화면의 프로필 선택·목록 다시 읽기·연결·해제·수동 상태 확인. 프로필 선택만으로 AWS에 자동 연결하지 않는다.
- 프로필 전환·연결 해제 확인은 앱 다크 테마 모달로 표시한다. 사용자가 취소하면 연결 변경을 진행하지 않는다.
- AWS SDK for .NET의 로컬 프로필 조회와 STS `GetCallerIdentity` 호출 경계. 성공 시 프로필명·전체 계정 ID·Caller ARN·마지막 확인 시각을 전역 상태와 화면에 표시하도록 구현했다.
- STS 인증 성공 시 같은 프로필 자격 증명 세션을 활성화하고, 세션의 EC2/RDS/S3 읽기 API로 조회하도록 구현했다. 연결 세대가 바뀐 뒤 도착한 예전 조회 결과는 화면에 반영하지 않는다.
- `그룹 만들기` 메뉴에 EC2/RDS 리전 선택과 서비스별 수동 조회 화면을 연결했다. EC2 이름/ID/유형/상태, RDS 식별자/엔진/상태, S3 버킷/리전을 표시하며 조회 실패 시 기존 목록을 보존한다. 리전 선택 상자·서비스 탭·목록 표를 공통 다크 테마에 맞게 수정했다. 이 화면은 그룹 생성 마법사에 통합되기 전의 조회 단계 화면이다.
- 프로필 전환·해제 확인, 새 프로필 인증 실패 시 기존 연결 유지, 인증 무효 시 재연결 필요 표시, 비동기 명령과 취소 토큰 전달.
- 마지막 **선택** 프로필명만 사용자별 JSON 설정에 저장·복원. 인증 비밀 값이나 그룹 정보는 이 저장소에 기록하지 않는다.

## 5. 발견된 문제와 미해결 사항

- **Day 1 완료 조건 미충족:** 정상 목록 조회 이외의 Mock 검증, 그룹 생성·등록, 그룹 JSON 저장·복원, 그룹 카드가 남아 있다.
- **리소스 조회 예외 경로 검증 대기:** 서비스별 정상 조회는 사용자 보고로 확인했다. 빈 목록·권한 거부·네트워크 실패와 Mock 검증은 아직 없다.
- **새 연결 확인 모달 GUI 재확인 대기:** 사용자는 조회 화면의 리전 드롭다운·세 탭·표 헤더 및 행 선택 색상에 문제가 없다고 확인했다. 프로필 전환·연결 해제에 뜨던 시스템 확인창을 앱 테마 모달로 교체했으며, 새 모달의 실제 표시와 확인·취소 동작은 사용자 화면에서 미확인이다.
- **그룹 생성 미구현:** 현재 조회 화면은 선택 목록을 보여주는 임시 작업 화면이다. 그룹 이름·계정·리전 저장, 서비스 선택과 리소스 선택의 마법사 연동은 다음 개발 범위다.

## 6. 다음 작업

1. 사용자가 프로필 전환·연결 해제 모달의 표시와 확인·취소 동작을 실제 화면에서 확인한다. 조회 화면의 빈 목록·권한 부족·네트워크 오류 결과도 확보되면 구분해 기록한다.
2. Mock/Fake 검증을 추가해 서비스별 성공·빈 결과·오류와 이전 연결 결과 폐기를 확인한다.
3. 기존 우선순위대로 그룹 생성 마법사·리소스 선택 연결, 중복 방지, 계정 ID/리전 확인, 그룹 JSON 저장·복원, 그룹 카드 대시보드를 구현한다.

## 3. 현재 코드에 구현된 주요 기능

- WPF 다크 테마 셸, 공통 `ResourceDictionary`, MVVM 내비게이션, 대시보드 빈 상태와 그룹 화면 이동 버튼.
- AWS 연결 관리 화면의 프로필 선택·목록 다시 읽기·연결·해제·수동 상태 확인. 프로필 선택만으로 AWS에 자동 연결하지 않는다.
- AWS SDK for .NET의 로컬 프로필 조회와 STS `GetCallerIdentity` 호출 경계. 성공 시 프로필명·전체 계정 ID·Caller ARN·마지막 확인 시각을 전역 상태와 화면에 표시하도록 구현했다.
- 프로필 전환·해제 확인, 새 프로필 인증 실패 시 기존 연결 유지, 인증 무효 시 재연결 필요 표시, 비동기 명령과 취소 토큰 전달.
- 마지막 **선택** 프로필명만 사용자별 JSON 설정에 저장·복원. 인증 비밀 값이나 그룹 정보는 이 저장소에 기록하지 않는다.

## 5. 발견된 문제와 미해결 사항

- **Day 1 완료 조건 미충족:** EC2/RDS/S3 조회, 그룹 생성·등록, 그룹 JSON 저장·복원, 그룹 카드와 Mock 검증이 남아 있다.
- **실행 결과 미확인:** 프로필 목록·연결·오류 분류·선택 프로필 복원·설정 손상 처리의 실제 GUI 및 AWS 동작은 확인되지 않았다.
- **향후 계정 안전 경계:** 현재 STS 인증은 호출 시 로컬 프로필을 해석하지만 검증된 자격 증명 세션을 리소스 호출용으로 보유하지 않는다. 조회 기능을 추가하기 전에 활성 연결의 자격 증명·계정·세대 식별을 묶어, 프로필 파일 변경 후 검증 계정과 API 호출 계정이 어긋나지 않게 해야 한다.
- **화면 명칭 차이:** 현재 사이드바는 `그룹 생성·관리`, `UI_DESIGN.md`는 `그룹 만들기`이며 그룹 관리는 그룹 상세에서 이동하도록 규정한다. 그룹 화면 구현 시 정합성을 맞춰야 한다.
